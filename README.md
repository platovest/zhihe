# 知合 ZHIHE

中文、非露骨的成年人关系沟通教育产品。**第 1 课完整免费，第 2–7 课付费**。目前尚未开放购买，后六课保持锁定，不提供面向用户的模拟开通。

未来面向海外，支付服务商之后再定，价格与币种尚未确定。当前仍在本地运行，无需 OpenAI 登录，不调用模型 API，不自动部署或发送邮件。七课已具备完整教学草稿，但尚未通过独立专业审阅。

当前规则与最新验收见 [免费与付费政策](docs/paid-course-policy.md)。早期演练文档是历史记录，不能当作当前已开通真实收款或公开上线的证据。

## 本地启动

需要 Node.js 24 或更高版本，建议使用 24 LTS。

```bash
npm ci
npm run admin:init
npm run dev
```

打开终端显示的本机地址（通常 `http://localhost:3000`；端口已被占用时自动顺延）。数据写入项目 `.wrangler/state/` 内的本地 SQLite 数据库，不上传 Cloudflare 云端。开发服务仅用于本机内测，不要暴露到公网。

页面：`/` 首页，`/learn` 七课目录，`/learn/expression` 免费第1课，`/learn/boundaries` 等各课路径，`/checkout` 购买方案，`/privacy` 隐私与撤回，`/terms` 演练规则，`/admin` 运营台。

## 免费与付费权限

第 1 课可直接完成全部练习并下载卡片，无需注册。目录展示全部七课，但第 2–7 课正文 API 默认返回 `403 purchase_required`，购买页显示“暂未开放购买”。完成首课、登记邮箱、旧测试 Cookie 或已模拟成功的订单都不能解锁。

旧用户端建单/模拟成功接口默认返回 `503 payment_unavailable`。内部状态机留作回归测试，只有隔离测试显式设置服务端 `ENABLE_COMMERCE_SIMULATION=true` 才能运行；不要在日常预览或未来公开服务开启。管理员可维护历史测试订单，但这些记录不是真实付款凭证。后续收款接入必须单独验证商户支付结果及真实权益。

## 运营台与数据

`npm run admin:init` 会在项目根目录创建 `.dev.vars`，权限为仅当前用户读写；已存在则保留，不会覆盖。用编辑器在本机打开该文件，把 `ADMIN_TOKEN=` 后的口令填入运营台。修改口令后重启服务。不要把口令发送到聊天、GitHub 或任何外部服务。未配置时管理接口拒绝访问。

口令仅保存在当前页面内存。运营台可查看登记、导出 CSV、修改人工跟进状态、核对后删除单条登记、手动清理超过 90 天的登记。删除不可在活动库内撤销；请同时处理导出和备份中的副本。涉及真实邮箱的人工外发须获运营者明确授权，只用于登记时同意的未来课程开放通知，不自动扩展为访谈或营销。

首次登记会给出撤回凭证，数据库只保留其哈希。重复邮箱不会增加记录或替换原凭证，也不会暴露邮箱是否存在；请保留第一次凭证。旧版记录没有凭证，或用户遗失凭证时，运营人员核对身份与请求后可在运营台定向删除，不得凭他人随口提供的邮箱删除。

练习选择不上传、不落盘。完成课号可在用户主动开启后保存到浏览器，关闭后删除。统计默认关闭，首页和课程页分别同意，只记录匿名事件次数，不关联订单；不是人数，也不能据此计算独立用户转化率。意向的90天清理目前是人工操作，没有后台定时任务；演练订单在每轮测试结束时通过取消/退款结束，再由管理员删除，备份也须同步处理。

## 备份与恢复

使用文件管理器定位 `.wrangler/state/` 下实际的 `.sqlite` 数据库，不要猜文件名。备份/导出都含个人信息，限制访问，不要提交到仓库；备份也须遵守撤回和保留期限。示例中的路径必须替换为核对过的完整路径，目标文件必须不存在：

```bash
node scripts/sqlite-snapshot.mjs /完整路径/源.sqlite /完整路径/新备份.sqlite
node scripts/sqlite-snapshot.mjs /完整路径/新备份.sqlite /完整路径/新恢复.sqlite
```

脚本执行 SQLite 一致性快照并校验完整性，拒绝覆盖已有目标。测试已覆盖真实文件备份→恢复到新路径→内容校验。恢复到活动开发库需要先停止服务，保留原库及其 WAL/SHM 文件，再由运营者明确确认切换；不要把文件直接覆盖到运行中的 D1 数据库。恢复旧备份后，必须重新应用备份后的撤回和过期清理。若无法可靠追溯撤回，不应恢复包含这些登记的旧备份。

## 验证

```bash
npm test
npm run lint
npm run typecheck
```

测试包含七课结构与内容、前端资源不含受限正文、可选本机记录、真实 SQLite 关闭重开、状态矩阵与竞态、跨会话权限、模拟退款撤权、旧表升级、登记/撤回、统计同意、CSV安全和备份恢复。GitHub Actions 会运行相同检查。当前验收见 [免费与付费政策](docs/paid-course-policy.md)；[七课演练记录](docs/verification-v2.md)与[首课阶段记录](docs/verification.md)保留为历史。

旧状态机的服务重启验证仅适用于显式开启测试开关的隔离服务，不能直接在默认用户预览执行。自动化测试自行注入开关，不需要修改日常配置；以下为历史工程验收命令（仅创建合成数据，finish后清理）：

```bash
node scripts/smoke-commerce.mjs create http://localhost:3001
# 停止并重启同一个本地服务后：
node scripts/smoke-commerce.mjs finish http://localhost:3001
```
