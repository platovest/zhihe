# 七课与本地交易演练验收

日期：2026-09-13。范围：在首课阶段 `75374bcc15f230a1e3f3319efe53f8bfcdb16c3d` 上继续完成七课内容草稿、学习交付和本地模拟交易。本文随本次源码提交保存；远端提交及 CI 结果以 GitHub 对应提交为准。

## 本版结果

七节课均有原创正文、情境反馈、自查、两道知识题及解析、课后行动与独立练习卡，不再只有标题。第 1 课免费，第 2–7 课由服务端依据本地订单状态检查权限，受限正文不编入公开前端资源。可选本机完成记录只存课号，默认关闭。

本地交易闭环：创建 → 失败或取消 → 模拟成功 → 开通课程 → 申请模拟退款 → 运营确认 → 撤销对应权益。订单由真实 SQLite 保存，不靠前端假状态。真实联络意向与演练订单分离。全部课程仍是待独立审阅草稿，全部交易均不扣款，不是支付商官方 sandbox 或正式经营。

## 运行中本地服务：已执行

地址 `http://localhost:3001`，本机开发服务及 `.wrangler/state/` 数据库。

1. 运行 `node scripts/smoke-commerce.mjs create http://localhost:3001`，得到 `COMMERCE_CREATE_OK`。核对免费课与六课拒绝、模拟失败、成功开通、无 Cookie 身份隔离。
2. 实际停止并重启同一开发服务。运行 `node scripts/smoke-commerce.mjs finish http://localhost:3001`，得到 `COMMERCE_RESTART_REFUND_OK`：同一订单仍为模拟成功、权益仍在；申请及运营确认模拟退款后撤权；清理该脚本自己创建的订单和本机临时凭据。
3. 浏览器原有演练订单在同一次服务重启后仍可读取。用户侧申请模拟退款，运营侧通过已鉴权本地 API 确认，再用原浏览器打开第 2 课，实际显示“这节课需要演练权益”。

上述证明的是本机状态及恢复，不是公网运维或支付机构验证。模拟失败保留待支付状态，并不伪称一笔真实失败交易。

## 浏览器：已执行

Codex 内置浏览器，桌面 1280×720；另检查 390×844 窄屏布局，完成后恢复默认尺寸。

- 七课目录加载；直达未授权第 2 课显示拒绝页，可转到演练订单。
- 订单页面：非绑定演练说明确认 → 创建 → 支付失败 → 取消 → 新建 → 模拟成功；订单和权益以服务端响应为准。
- 第 2 课：开始 → 方法 → 情境反馈 → 三项自查 → 两题知识检验（包含错误答案解释）→ 完成 → 下载练习卡，键盘操作可推进。下载文件实际存在且内容匹配本课。
- 退款确认后原浏览器受限课程拒绝；本轮两笔浏览器测试订单已按已取消/已退款条件定向删除，并确认列表无残留。未删除其他订单，未发送邮件、提交真实个人资料或处理真钱。
- 窄屏检查目录卡片、免费课入口与订单表单，三个页面的文档宽度和滚动宽度均为 390，无横向溢出；文字、未勾选状态和按钮可见。不是全部移动设备或浏览器兼容性认证。

本轮不声称逐个在浏览器完成七课全流程；七课共用渲染器，所有课的结构和 API 权限由自动化覆盖，浏览器完整路径抽验第 2 课。运营确认退款正向流程本轮通过 API 验证，并非登录后台逐按钮完整人工验收。登记与撤回本轮做自动化回归，前一阶段浏览器证据见 [首课阶段记录](./verification.md)。

## 已知限制与尚未执行

- 无真实收款、官方支付 sandbox、公开部署、自动外发、跨设备账号或支付事件对账；会话 Cookie 丢失不能自助找回演练订单。
- 首次建单响应及 Cookie 一起丢失时，全局幂等键拒绝重复建单，但不能跨身份找回原订单；这是本地演练限制，不能照搬到正式支付。
- 共享管理员口令与进程内限流仅适合本机小范围演练。订单列表最多显示最新 500 笔，演练闭单须及时清理；非正式商业运营后台。
- 撤权防止后续 API 读取，不会远程删除已下载的卡片。活动页面在重新读取/重新获得焦点时复查，不是数字版权保护。
- 未执行 20 人招募或学习收益研究；未取得独立真人内容审阅或任何机构背书。AI 内容与评审不替代这些事实。
- 根目标、分工、假设和上线条件已按 Karpathy 的最小必要变更与可验证结果、钱学森的目标分解及验证关口写入仓库。外部待办见 [上线准备清单](./launch-readiness.md)，实际招募材料及空表见 [研究执行包](./research-kit.md)。
