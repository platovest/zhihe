## 范围与结论

最小学习与意向运营流程已实现：完整免费首课 → 反馈与练习卡 → 自愿登记 → 本地持久化 → 受保护的运营查询/导出/人工处理 → 撤回删除。尚未验证真实学习收益和购买意愿；没有支付、自动邮件或公开部署。

运行环境为 macOS、Node 26、本地 vinext/Miniflare D1。源码约定 Node 24+，CI 使用 Node 24。预览验证地址为 `http://localhost:3001`，3000 已属于另一个项目，未停止或修改该服务。监听检查显示知合监听本机回环地址 `[::1]:3001`。

## 真实运行服务检查

`scripts/smoke-local.mjs create http://localhost:3001`：用唯一合成 `example.com` 邮箱检查无口令拒绝、练习卡实际 HTTP 返回、登记成功、管理查询、状态更新和 CSV 内容。

随后停止并重启知合服务，执行 `scripts/smoke-local.mjs finish http://localhost:3001`：同一条记录与状态仍存在；通过首次凭证撤回后管理查询确认该记录消失。测试登记及临时回执均已清理，没有发送邮件。

此检查可复现，先 create，再重启同一服务，再 finish。脚本只接受本机地址，口令从被 Git 排除的 `.dev.vars` 读取，不打印口令或名单。
