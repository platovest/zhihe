# 当前产品规则：1 课免费，6 课付费

更新时间：2026-09-13；本规则取代前一版面向用户的交易演练方案。用户已确认未来海外上线，支付商户与服务商之后再定，当前仍在本地运行。

## 产品决策

- 第 1 课完整免费：正文、练习、解析和练习卡不删减，无需注册。
- 第 2–7 课付费：目录和学习目标公开，正文需真正购买后才能取得。不得把点击模拟成功、完成首课或登记邮箱当作购买。
- 本轮尚无真实收款，购买页显示“暂未开放购买”，后六课保持锁定。该状态是支付接入未完成，不是六课免费。
- 海外正式价格、币种、服务地区、商户、支付机构和售后条件尚未确定；旧 ¥199 是历史试验价格，不当作海外正式售价。
- 公开页面不提供演练按钮。内部模拟订单仅作为工程测试数据，不是用户商品权益。

选择 1 课免费是针对目前共 7 课的产品判断：给出一节完整价值体验，同时为后续进阶内容保留清楚的付费范围。暂不增加到 2–3 课，也不把 1/7 宣称为最优转化率；以后用首课完成、购买入口点击和真实付款数据验证。仅部分课程免费、其余引导购买的机制也见 [Thinkific 官方免费预览说明](https://support.thinkific.com/hc/en-us/articles/360030722473-Create-a-Free-Course-Preview)，该资料不证明本产品免费一课必然最佳。

## 工程边界

默认运行不设置 `ENABLE_COMMERCE_SIMULATION`。免费课程 API 直接返回第一课，其余六课 `403 purchase_required`；创建/模拟支付/退款等旧用户端接口返回 `503 payment_unavailable`。旧模拟 Cookie、已成功的模拟订单、请求参数或 HTTP header 均不能开通。

仅隔离自动化测试通过服务端环境绑定显式注入 `ENABLE_COMMERCE_SIMULATION=true`，保留上一版状态机回归。不要在给用户看的本地服务或未来公开环境开启此开关。管理员仍可维护历史模拟数据，不创建真钱订单。

通知登记使用新版本 `overseas-launch-v2`，不与历史 `founding-199-v1` 价格意向混淆。旧记录不改写；通知登记也不是购买意愿已验证，不能把两个版本直接合并计算价格接受率。

后续真实支付接入必须单独实现真实订单与权益：依据支付服务商验证过的结果授予，不复用模拟订单为已付款证据。真实身份/找回、签名回调、金额币种核对、退款和对账均需验收后才开售。
